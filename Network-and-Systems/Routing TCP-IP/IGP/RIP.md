# Intro.

The Routing Information Protocol (RIP) was the first Interior Gateway Protocol built on top of TCP that find widespread use in [[ARPANET]]. The protocol was a distance-vector routing protocol that used to route traffic behind the core gateways of ARPANET (this was way before any concept of autonomous system was conceived, [[EGP]] was where that term was coined).

GGP and EGP served their purpose to slow down the rapid growth of ARPANET for some time. While they were successful, they did not solve the scaling problems of ARPANET, and EGP itself did not use the autonomous system hierarchy that it actually proposed, the pair were merely and intermediate state between the ARPANET and the Internet.
